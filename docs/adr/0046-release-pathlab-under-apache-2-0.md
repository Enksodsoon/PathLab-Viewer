# Release PathLab under Apache-2.0

PathLab-authored production code and documentation will be released under Apache-2.0 with a root `LICENSE`, `NOTICE`, SPDX headers, third-party notices, and CycloneDX plus SPDX Release Bills of Materials. Production admission fails on UNKNOWN, NOASSERTION, noncommercial, research-only, source-available, or incompatible copyleft dependencies and unproven assets; the current AGPL viewer package and unknown-license dependency must be replaced or cleanly isolated outside the Apache release boundary before Full-Surface Launch.
