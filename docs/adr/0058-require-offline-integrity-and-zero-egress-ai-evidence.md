# Require offline integrity and zero-egress AI evidence

Each Teacher AI bundle must complete an airplane-mode hard reload and 20 generations with zero third-party requests, zero model-network bytes on cache hit, and network-capture proof that prompts, sources, and outputs have zero egress. Corrupted artifacts fail closed, interrupted updates atomically restore the last-known-good bundle, cache or service-worker loss returns to Deterministic Authoring Templates, and prompt injection cannot expose unapproved sources, publish, grade, invoke tools, or trigger any remote fallback.
