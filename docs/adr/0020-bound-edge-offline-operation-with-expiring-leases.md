# Bound Edge offline operation with expiring leases

An Edge Node may perform its granted offline capabilities for no more than seven consecutive days under a signed Node Lease. User authorization must be renewed locally at least every 24 hours against the cached institution policy, synchronization supports only protocol versions N through N-2, and expiry makes governed content read-only while blocking new acquisitions and other governed writes until the node reconnects, validates time and policy, upgrades if required, and receives fresh leases.
