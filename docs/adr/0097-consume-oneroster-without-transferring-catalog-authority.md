# Consume OneRoster without transferring Catalog authority

PathLab will consume OneRoster 1.2 REST read-only, with OneRoster CSV 1.2.1 as an administrator-controlled fallback, and turn valid imports into reviewed proposals and new Learning Catalog versions. A roster exchange never silently replaces active Catalog state, and grade return occurs only through the LTI Assignment and Grade Services profile rather than OneRoster writeback.
