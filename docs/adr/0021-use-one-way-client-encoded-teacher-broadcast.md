# Use one-way client-encoded Teacher Broadcast

Zero-Cash Production will provide teacher audio/video as one publisher forwarded to receive-only students by an open, self-hosted selective forwarding unit. Encoding occurs on the teacher client, the server performs neither transcoding nor recording, students do not publish media, and congestion, saturation, or media-process failure automatically falls back to synchronized slides and text without interrupting the Class Session or losing Durable Interactions.
