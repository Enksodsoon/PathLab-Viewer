# Interface design references

This directory contains visual references for the PathLab Viewer interface.

- [`admin-concept.png`](admin-concept.png) — administrator library and slide-management direction
- [`viewer-concept.png`](viewer-concept.png) — public viewer direction

These images are design references rather than release evidence. The maintained product and theme contracts live in [`apps/web/PRODUCT.md`](../../apps/web/PRODUCT.md) and [`apps/web/DESIGN.md`](../../apps/web/DESIGN.md). Current verification belongs in [`docs/evidence/QA.md`](../evidence/QA.md).

Durable architecture decisions should be documented in `docs/architecture`. Temporary implementation plans, assistant workspaces, and tool-specific task reports should remain outside the repository.
