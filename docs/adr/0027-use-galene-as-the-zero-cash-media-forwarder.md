# Use Galene as the Zero-Cash media forwarder

Zero-Cash Production will use Galene 1.1 pinned at commit `da062e782e78dd55df8f17223cae57222bf871ee` as an unprivileged native Linux ARM64 system service. PathLab will build it with `CGO_ENABLED=0`, grant teachers presenter/operator permissions and learners observe-only permissions through short-lived signed tokens, restrict launch media to VP8 plus Opus, disable recording and server transcoding, and avoid Redis, a media database, or a paid TURN dependency. This selection remains unqualified until the exact host passes the 1,200-Classroom-plus-100-viewer campaign, direct-UDP and TURN connectivity tests, authorization abuse tests, supported-browser checks, and automatic Media Fallback; failure blocks the Full-Surface Launch claim.
