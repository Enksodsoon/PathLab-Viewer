# Use Institution language and composable governed roles

PathLab will use Institution as the canonical public and domain term; `organization_id` may remain only as a temporary internal migration field. Institution-scoped Role Bindings are composable and use the fixed role names Owner, Administrator, Instructor, Teaching Assistant, Assessor, Moderator, Researcher, EQA Manager, Clinical Privacy Steward, WSI Reviewer, Publication Officer, Auditor, Operator, and Key Custodian.
