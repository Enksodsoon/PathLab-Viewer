# Make every planned context a zero-cash launch gate

Zero-Cash Production will remain blocked until every planned PathLab context has an end-to-end production implementation and qualification path on the single zero-cash host, including teaching, Assessment, local AI, Clinical Shadow, Research, EQA, Edge Federation, imaging and institutional interoperability, advanced media, and operations. This is a full-surface launch rather than a core-first release; the operating-mode decision separately determines which contexts may be resident or active at the same time.
