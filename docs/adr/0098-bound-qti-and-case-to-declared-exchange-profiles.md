# Bound QTI and CASE to declared exchange profiles

PathLab will import and export QTI 3.0 using corrected 3.0.1 artifacts only for the Basic auto-scoreable, hotspot, and shared-stimulus profile, while consuming CASE 1.1 frameworks read-only. Native essays, WSI interactions, and unsupported items carry no QTI claim, and QTI Results, CAT, PCI, and Usage Data plus CASE writeback are excluded.
