# Require expiring purpose-bound Processing Grants

An Institution must issue an expiring Processing Grant before PathLab processes governed learner or participant data, naming its authority, purpose, data classes, and any required guardian authorization. PathLab stores only the minimum necessary Minor Status rather than a full birth date unless the Institution explicitly proves that need; withdrawal or expiry blocks new processing and schedules deletion under the applicable Retention Schedule, with suspension permitted only by a valid Legal Hold.
