# Emit minimized optional Caliper and exclude overlapping standards

The Integration Gateway may run a default-off Caliper Analytics 1.2 Sensor limited to minimized Session, Reading, Media, Assessment, and Tool Use profiles, with no WSI pixels, answers, prompts, free text, or identity-rich payloads. xAPI, SCORM, Common Cartridge, and general OIDC single sign-on are excluded from v1 because they duplicate the selected exchange paths or enlarge privacy and support obligations without a named production requirement.
