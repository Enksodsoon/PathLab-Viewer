# Implement full read-only DICOMweb for two microscopy SOP classes

PathLab will claim read-only DICOMweb conformance against DICOM 2026c only after it implements every mandatory QIDO-RS Search and WADO-RS Retrieve resource in PS3.18 Table 10.3-2 plus the PS3.18 Retrieve Capabilities transaction. The admitted object surface is limited to VL Whole Slide Microscopy Image Storage (`1.2.840.10008.5.1.4.1.1.77.1.6`) and Microscopy Bulk Simple Annotations Storage (`1.2.840.10008.5.1.4.1.1.91.1`). STOW-RS, DIMSE, Clinical Writeback, and every other write path are excluded; unsupported methods return `405`, unsupported SOP Classes are rejected, and a deployment that omits any mandatory read or capability resource must describe itself as a DICOMweb-compatible subset rather than conformant.
