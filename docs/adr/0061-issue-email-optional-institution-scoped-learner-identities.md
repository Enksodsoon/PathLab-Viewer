# Issue email-optional Institution-scoped learner identities

A learner Membership is created only by an Institution roster/import or one-time invitation and receives an opaque Institution-scoped Learner Identifier. Activation requires a single-use Activation Grant plus a password, may add a passkey, and never requires email; recovery uses a staff-issued single-use Recovery Grant, revokes all existing sessions, and is audited. A Classroom join code locates an eligible Class Session but cannot create, authenticate, merge, or replace a Principal or Membership.
