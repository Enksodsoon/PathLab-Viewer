# Separate plan, build, deploy, qualification, and activation

PathLab will report planning, implementation, local or protected checks, merge, deployment, pilot, qualification, and activation as separate states. Only an exact release and host that completes every gate plus a supervised limited pilot may receive a `SUCCESS` Full-Surface production result; `PARTIAL`, `NEGATIVE`, or `NOT_EVALUABLE` cannot be promoted, and security, licensing, backup, recovery, clinical-boundary, or zero-cash failures have no waiver.
