# Require institution-declared fail-closed data residency

Production activation requires every Institution to publish a versioned Residency Policy that names approved jurisdictions and locations for each governed data class. PostgreSQL data, immutable objects, WAL archives, encrypted off-host backups, Research processing, integrations, telemetry, and exports must remain within Approved Data Locations; undeclared external storage, processing, or transfer is denied by default, and any permitted movement requires an auditable purpose-bound Transfer Grant.
