# Scale by home cell and single-writer ownership

The Funded Scalable Profile will preserve the Zero-Cash domain contracts while splitting processes, databases, object delivery, workers, and media forwarders as measured pressure requires. Each Institution has one authoritative home cell and each Class Session one owner, avoiding active-active shared writes; a sustained approach to 70 percent of a qualified resource envelope or an unmet availability or durability requirement triggers the next split while software freedom remains unchanged and added infrastructure cost stays explicit.
