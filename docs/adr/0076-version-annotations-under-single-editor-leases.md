# Version annotations under single-editor leases

Annotation authoring will use owner-private drafts and one expiring Annotation Editor Lease per layer; optimistic predecessor checks produce immutable purpose- and audience-bound Annotation Layer Versions capped at 25,000 objects and 50 MB. Clients lazy-load by viewport, imported GeoJSON remains quarantined until schema, geometry, coordinate, and provenance validation, and invalid geometry or uncalibrated measurements are rejected; realtime CRDT editing, multi-editor mutation, and last-write-wins are outside the Zero-Cash launch.
