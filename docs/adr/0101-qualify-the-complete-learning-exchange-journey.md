# Qualify the complete learning exchange journey

Learning interoperability will be self-qualified end to end through OneRoster, CASE, QTI, LTI, PathLab Assessment, Assignment and Grade Services, Open Badges, CLR, and the optional Caliper boundary before activation. An unavailable external endpoint queues or fails closed without changing Learning Catalog, Assessment, Trust and Governance, or Credential Ledger authority, and PathLab will publish profile evidence without claiming paid 1EdTech certification.
