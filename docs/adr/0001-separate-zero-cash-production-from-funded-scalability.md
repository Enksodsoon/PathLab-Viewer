# Separate zero-cash production from funded scalability

PathLab will provide a bounded, non-HA Zero-Cash Production Profile whose incremental external cash spend is verified as zero, while future high-availability and higher-capacity deployments use a separate Funded Scalable Profile. Both profiles preserve the same freely licensed PathLab feature code, but the zero-cash profile cannot inherit availability, durability, or capacity claims that require additional infrastructure; this prevents temporary cloud allowances from being mistaken for a permanent production guarantee.
