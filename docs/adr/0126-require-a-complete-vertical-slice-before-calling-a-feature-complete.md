# Require a complete vertical slice before calling a feature complete

A PathLab feature is complete only when its domain authority, migration, API, discoverable accessible UI, authorization, persistence and restart behavior, retention and deletion, audit and observability, backup or rebuild contract, resource limits, failure behavior, security evidence, browser/device evidence, operations, migration/rollback, and exact-release qualification are all present. A route, mock, feature flag, passing unit test, deployment, or isolated implementation slice cannot satisfy this definition.
