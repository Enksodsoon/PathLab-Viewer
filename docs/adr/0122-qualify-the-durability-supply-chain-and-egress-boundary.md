# Qualify the durability supply chain and egress boundary

Mandatory durability tools will be admitted only from pinned upstream source revisions and qualified Linux ARM64 artifacts and runtimes, with verified signatures or checksums, licenses, provenance, SBOMs, and component-appropriate security scans and tests; Barman's architecture-independent Python source is qualified on the exact ARM64 Python/runtime package rather than mislabeled as native ARM64 source. OWASP ASVS 5.0.0 Level 2 applies to the PathLab web application and applicable HTTP control surfaces, including the object-pull and rest-server boundaries, with every non-applicable control justified; it is not asserted as a blanket certification of backup CLI tools. GPL software such as Barman remains a separately executed and distributed work with its source and notices rather than entering the Apache PathLab binaries. Qualified patch candidates are evaluated monthly, a reachable Critical vulnerability blocks production immediately, a High vulnerability requires a documented mitigation that expires within 30 days, affected evidence receives targeted requalification plus the final-candidate soak without resetting unaffected campaign evidence, and production, backup, build, and restore paths use default-deny egress with no mandatory hosted or paid service.
