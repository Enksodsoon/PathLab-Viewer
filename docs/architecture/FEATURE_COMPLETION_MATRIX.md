## Completion semantics

For every row, completion requires all of the following in the same exact release: schema and migration; owning service path; accessible discoverable UI where human use exists; authorization and separation of duty; state, restart, idempotency and concurrency behavior; retention, deletion and legal-hold behavior; audit and local operations; backup or explicit rebuild contract; resource/failure limits; tests and adversarial evidence; browser/device or independent-reader evidence; install/upgrade/rollback and runbook; and a current Qualification Claim. Any missing column leaves the row incomplete.
