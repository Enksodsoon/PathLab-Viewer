# Run Teacher AI only on the teacher device

Teacher AI inference will run entirely on the educator's device from an admitted signed offline Model Bundle; prompts, source materials, learner data, and outputs will not be sent to PathLab servers or external AI services. Every generated proposal remains an Authoring Draft with local Generation Record until explicit teacher approval, the model cannot publish or grade, and unsupported devices use Deterministic Authoring Templates so no server inference or paid API becomes mandatory.
