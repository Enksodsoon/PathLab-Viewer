# Separate producer-bound warm stage analysis

This is additive posthoc analysis of the preserved 9eab warm campaign. The original warm stage report remains unchanged and unmeasured under its explicit-geometry guard. No missing geometry flags were inferred or added.

All 24 accepted hybrid initializer sidecars were independently bound to the original JPEG bytes and header dimensions, exact registered-directory digests, frozen producer code, completed atomic invocation, requested/effective settings, engine identity, runtime receipt and final-map descriptor. The producer passes full JPEG dimensions unchanged, rescales initializer coordinates to that frame, persists the initializer before warping, and inverse-projects residual source cells into the original moving frame. The original JPEG image extent is the coordinate frame; tissueCrop affects support masking, not an inferred spatial crop origin.

There are 96 planned hybrid invocation rows: 24 measured (native-valis 12, native-wsireg 8, valis-rigid-wsireg 4) and 72 unmeasured because no accepted final map was available. Orphan initializer files are not admitted. Each call retains the fixed cohort of 947 eligible published landmarks; this per-pair stage table reports the actual pair denominator instead of treating unmeasured stages as measured zero support.

The initializer engine-output score and the affine actually applied for warping are separate. The affine projection is restricted to recorded initializer source cells; the whole piecewise initializer map was not applied to the warp. Final-versus-stage error comparisons use identical commonly supported landmarks. P95 values from different pairs/support subsets are not averaged. Residual warp-frame anatomical accuracy is unmeasured.
