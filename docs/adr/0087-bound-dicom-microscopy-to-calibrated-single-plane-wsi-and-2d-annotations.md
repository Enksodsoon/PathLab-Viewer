# Bound DICOM microscopy to calibrated single-plane WSI and 2D annotations

Each admitted VL Whole Slide Microscopy object will describe exactly one specimen, one optical path, and one focal plane as calibrated 8-bit color with `DimensionOrganizationType=TILED_FULL`; concatenations are unsupported. Accepted transfer syntaxes are Explicit VR Little Endian, JPEG Baseline (Process 1), JPEG 2000 Lossless Only, and JPEG 2000. Each Microscopy Bulk Simple Annotations object will use two-dimensional image coordinates with `PixelOriginInterpretation=VOLUME`, reference exactly one admitted WSI, and contain only point, polyline, polygon, ellipse, or rectangle geometries. Missing calibration, ambiguous frame mapping, invalid geometry, unsupported transfer syntax, or incomplete algorithm and provenance fields causes fail-closed rejection.
