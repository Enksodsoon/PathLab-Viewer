# Integrate as a manually registered LTI Tool only

PathLab will implement LTI Core 1.3.0 as a manually registered Tool with Deep Linking 2.0, read-only Names and Role Provisioning Services 2.0, and read/write Assignment and Grade Services 2.0. It will not act as an LTI Platform, support dynamic registration or just-in-time identity creation, or permit clinical, administrative, or authoring launches.
